

# Tikz-Graphics

Este repositorio contiene ejemplos de código LaTeX Tikz para gráficos y la salida del código renderizado en formato .png. Los ejemplos se generan para revisiones de laboratorio, notas y artículos. La inspiración provenía a menudo de las páginas [tikz.net](https://tikz.net), donde puedes encontrar algunas de mis ilustraciones, y [texample.net](https://texample.net/tikz/examples/), donde puedes encontrar una gran cantidad de ilustraciones destacadas.

## Propósito 

El propósito de este proyecto es sugerir y proporcionar formas de plasmar ideas gráficas abstractas en código Tikz y utilizarlas para crear figuras para publicaciones, libros
o cualquier proyecto personal que tengas en mente.
